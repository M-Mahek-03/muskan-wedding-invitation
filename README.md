# 💍 Muskan & Rahil — Wedding Invitation

A beautiful, interactive digital wedding invitation built with **React** and **Vite**. Crafted with love for the Nikah ceremony of **Rahil Inayat Karbelkar** and **Muskan Mustufa Tickley**.

---

## ✨ Features

- 🕌 **Animated Envelope** — An interactive 3D envelope with a wax seal that opens to reveal the invitation
- 🌙 **Islamic Theme** — Arabic Bismillah, gold and forest green palette, elegant serif typography
- 📅 **Event Cards** — Detailed cards for Haldi, Mehendi, Engagement, and Nikah celebrations
- 📍 **Google Maps Integration** — Direct venue links for every event
- 🕯️ **Floating Lights Animation** — Ambient golden particles for atmosphere
- 📜 **Scroll Reveal Animations** — Smooth entrance animations as you scroll
- 📱 **Fully Responsive** — Optimised for mobile, tablet, and desktop
- ♿ **Accessible** — Keyboard navigable, screen reader friendly, respects `prefers-reduced-motion`
- 🔁 **Replay Feature** — Re-experience the full invitation from the beginning

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| [React 19](https://react.dev/) | UI components & state management |

| [Manrope](https://fonts.google.com/specimen/Manrope) | Body text |

| IntersectionObserver API | Scroll-based reveal animations |

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v18 or higher
- npm v9 or higher

### Installation

```bash
# Clone the repository
git clone https://github.com/M-Mahek-03/muskan-wedding-invitation.git

# Navigate into the project
cd muskan-wedding-invitation

# Install dependencies
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
